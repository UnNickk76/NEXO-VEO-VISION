# Report tecnici Codex

Questa cartella conserva un resoconto permanente di ogni attività svolta da
Codex nel repository.

- I rapporti storici hanno nome
  `YYYY-MM-DD_HHMMSS_descrizione-breve.md`, con data e ora UTC.
- `LATEST.md` contiene una copia integrale del rapporto più recente e indica in
  apertura il relativo percorso storico.
- I rapporti storici sono immutabili: non devono essere sovrascritti o
  eliminati.
- Ogni rapporto viene incluso nella stessa pull request dell'attività che
  documenta, anche quando l'attività è soltanto diagnostica, parziale o fallita.

Le regole complete e vincolanti sono definite nel file `AGENTS.md` alla radice
del repository.
